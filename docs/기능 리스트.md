# 기능 리스트 (Version 1)

- **문서명**: 기능 리스트
- **목적**: 상권 탐색 서비스의 기능 및 요구사항 정의
- **문서 상태**: Published / Version 1
- **작성 기준일**: 2026-09-07

현재 프로젝트 구조와 구현된 프론트엔드·백엔드 기능을 기준으로 작성한 요구사항 명세입니다.

| 번호  | 사용자 경험                                                    | 세부 구현                                                              |
| :---: | :------------------------------------------------------------- | :--------------------------------------------------------------------- |
|   1   | 사용자는 서울 상권 탐색 화면에 진입할 수 있다.                 |                                                                        |
|  1-1  | 사용자가 서비스 루트에 접속하면 상권 탐색 화면으로 이동한다.   | `/` 접속 시 `/explore`로 리다이렉트한다.                               |
|  1-2  | 존재하지 않는 경로에 접속하면 상권 탐색 화면으로 이동한다.     | 잘못된 경로는 `/explore`로 리다이렉트한다.                             |
|  1-3  | 사용자는 공통 헤더를 확인할 수 있다.                           | 모든 페이지 상단에 `Header` 컴포넌트를 표시한다.                       |
|  1-4  | 사용자는 공통 푸터를 확인할 수 있다.                           | 서비스명, 저작권, 방법론 및 API 정보를 표시한다.                       |
|   2   | 사용자는 업종·자치구별 추천 상권을 조회할 수 있다.              | 자치구는 `district.signgu_cd` 기준으로 필터링하고 상권 단위로 비교한다. |
|  2-0  | 사용자는 자치구 목록을 조회할 수 있다.                          | `GET /api/v1/districts`에서 `signgu_cd`, `signgu_cd_nm`을 조회한다.      |
|  2-0  | 사용자는 자치구를 선택해 상권을 필터링할 수 있다.                | 선택한 `signgu_cd`를 `trade_area.signgu_cd`와 연결해 필터링한다.         |
|  2-1  | 업종 선택 창을 확인할 수 있다.                                 | 커피·음료, 한식, 치킨, 편의점, 의류, 미용 업종을 제공한다.             |
|  2-2  | 업종을 변경할 수 있다.                                         | 선택한 `industry_code`를 기준으로 추천 상권 API를 호출한다.            |
|  2-3  | 분석 기준 분기 선택 창을 확인할 수 있다.                       | 2026 Q2, 2026 Q1, 2025 Q4를 제공한다.                                  |
|  2-4  | 분석 기준 분기를 변경할 수 있다.                               | 선택한 `quarter`를 추천 상권 API에 전달한다.                           |
|  2-5  | 추천 상권 목록을 확인할 수 있다.                               | 순위, 상권 코드, 상권명, 상권 유형, 탐색 점수, 주요 지표를 표시한다.   |
|  2-5a | 추천 상권의 자치구 정보를 확인할 수 있다.                      | `signgu_cd`, `signgu_cd_nm`을 표시한다.                                 |
|  2-6  | 추천 상권별 탐색 점수를 확인할 수 있다.                        | 매출 성장 점수 40%, 거래 활성도 점수 35%, 경쟁 점수 25%를 종합한다.    |
|  2-7  | 추천 상권별 지표 상태를 확인할 수 있다.                        | 성장성, 거래량, 경쟁 여건을 높음·보통·낮음으로 표시한다.               |
| 2-10  | 추천 상권별 분석 인사이트를 확인할 수 있다.                    | 추천 이유와 데이터 기반 설명을 표시한다.                               |
| 2-11  | 경쟁 여건에 대한 분석 인사이트를 확인할 수 있다.               | 실제 점포 수가 아닌 매출·거래 데이터 기반 Proxy임을 안내한다.          |
| 2-12  | 추천 점수 산정 기준을 확인할 수 있다.                          | 성장 점수 40%, 거래 활성도 점수 35%, 경쟁 점수 25%를 표시한다.         |
| 2-13  | 경쟁 점수의 산출 기준을 확인할 수 있다.                        | 객단가 경쟁력 50%, 성장 균형 30%, 수요 다양성 20%를 적용한다.          |
| 2-14  | 추천 점수가 창업 성공을 보장하지 않음을 확인할 수 있다.        | 추가 조사와 현장 실사가 필요하다는 안내를 표시한다.                    |
|   3   | 사용자는 추천 상권의 상세 분석 화면으로 이동할 수 있다.        |                                                                        |
|  3-1  | 추천 상권을 클릭하면 상세 분석 화면으로 이동한다.              | `/district/{trade_area_code}` 경로로 이동한다.                         |
|  3-2  | 상세 화면 이동 시 업종과 분기 조건을 유지한다.                 | URL query string에 `industry`, `quarter`를 전달한다.                   |
|  3-3  | 상세 화면에서 다른 상권을 선택할 수 있다.                      | 상권 선택 드롭다운을 제공한다.                                         |
|  3-4  | 상세 화면에서 탐색 목록으로 돌아갈 수 있다.                    | `/explore` 이동 링크를 제공한다.                                       |
|   4   | 사용자는 상권의 핵심 지표를 확인할 수 있다.                    |                                                                        |
|  4-1  | 추정 매출을 확인할 수 있다.                                    | 원 단위 원천값과 억 단위 표시값을 제공한다.                            |
|  4-2  | 거래 건수를 확인할 수 있다.                                    | 원천 거래 건수와 만 단위 표시값을 제공한다.                            |
|  4-3  | 서울 내 상권 순위를 확인할 수 있다.                            | 해당 상권의 서울 전체 순위를 표시한다.                                 |
|  4-4  | 전분기 대비 매출 성장률을 확인할 수 있다.                      | `qoq_growth_rate`를 백분율로 표시한다.                                 |
|  4-5  | 매출 및 거래량 백분위 정보를 확인할 수 있다.                   | 서울 상권 대비 상대적 위치를 표시한다.                                 |
|  4-6  | 매출, 거래량, 경쟁 여건 수준을 확인할 수 있다.                 | 매우 높음, 높음, 보통, 낮음 단계로 표시한다.                           |
|   5   | 사용자는 상권별 순위를 비교할 수 있다.                         |                                                                        |
|  5-1  | 매출 기준 순위를 선택할 수 있다.                               | 상권을 매출 순으로 정렬한다.                                           |
|  5-2  | 거래량 기준 순위를 선택할 수 있다.                             | 상권을 거래 건수 순으로 정렬한다.                                      |
|  5-3  | 성장률 기준 순위를 선택할 수 있다.                             | 상권을 매출 성장률 순으로 정렬한다.                                    |
|  5-4  | 탐색 점수 기준 순위를 선택할 수 있다.                          | 상권을 종합 점수 순으로 정렬한다.                                      |
|  5-5  | 현재 조회 중인 상권을 구분할 수 있다.                          | 현재 상권을 순위 목록에서 강조한다.                                    |
|   6   | 사용자는 상권의 소비 패턴을 확인할 수 있다.                    |                                                                        |
|  6-1  | 시간대별 소비 패턴을 확인할 수 있다.                           | 시간대별 매출 비율과 매출 금액을 그래프로 표시한다.                    |
|  6-2  | 주요 소비 시간대를 확인할 수 있다.                             | 최고 매출 시간대를 강조 표시한다.                                      |
|  6-3  | 연령대별 소비 패턴을 확인할 수 있다.                           | 10대, 20대, 30대, 40대 이상 비율을 표시한다.                           |
|  6-4  | 성별 소비 비율을 확인할 수 있다.                               | 연령대별 여성·남성 비율을 표시한다.                                    |
|  6-5  | 주요 고객층을 확인할 수 있다.                                  | 소비 비율이 가장 높은 연령·성별 고객층을 표시한다.                     |
|  6-6  | 요일별 소비 패턴을 확인할 수 있다.                             | 월요일부터 일요일까지 소비 비율을 표시한다.                            |
|  6-7  | 주요 소비 요일을 확인할 수 있다.                               | 평균 대비 차이와 함께 최고 소비 요일을 표시한다.                       |
|   7   | 사용자는 상권의 경쟁 여건을 확인할 수 있다.                    | 실제 점포 수가 아닌 데이터 기반 Proxy로 산출한다.                      |
|  7-1  | 경쟁 점수를 확인할 수 있다.                                    | `CompetitionScore`를 동일 분기·동일 업종 상권 집단과 비교한다.         |
|  7-2  | 객단가 경쟁력 요소를 확인할 수 있다.                           | 매출액을 거래건수로 나눈 평균 객단가를 정규화해 반영한다.              |
|  7-3  | 성장 균형 요소를 확인할 수 있다.                               | 거래 성장률과 매출 성장률의 차이를 반영해 점수를 산출한다.             |
|  7-4  | 수요 다양성 요소를 확인할 수 있다.                             | 상권 내 업종별 매출 비중과 HHI를 이용해 수요 다양성을 산출한다.        |
|  7-5  | 경쟁 여건 해석의 한계를 확인할 수 있다.                        | 점포 수나 경쟁사 수를 직접 측정한 값이 아니라는 안내를 표시한다.       |
|   8   | 사용자는 여러 상권을 비교 목록에 추가할 수 있다.               |                                                                        |
|  8-1  | 추천 상권을 비교 목록에 추가할 수 있다.                        | 상권 카드의 비교 버튼을 제공한다.                                      |
|  8-2  | 상세 화면에서 현재 상권을 비교 목록에 추가할 수 있다.          | `비교함 담기` 버튼을 제공한다.                                         |
|  8-3  | 비교 목록에 추가된 상권을 구분할 수 있다.                      | 체크 아이콘과 `비교함 선택됨` 상태를 표시한다.                         |
|  8-4  | 비교 목록에서 상권을 제외할 수 있다.                           | 선택된 상권을 다시 클릭하면 목록에서 제거한다.                         |
|  8-5  | 비교 대상은 최대 3개까지 유지한다.                             | 3개 초과 시 가장 먼저 선택된 상권을 제거하고 새 상권을 추가한다.       |
|  8-6  | 비교 대상이 1개만 남은 경우 삭제하지 않는다.                   | 최소 1개 상권이 유지되도록 처리한다.                                   |
|   9   | 사용자는 선택한 상권을 한 화면에서 비교할 수 있다.             |                                                                        |
|  9-1  | 비교 화면으로 이동할 수 있다.                                  | `/compare` 경로를 제공한다.                                            |
|  9-2  | 비교 대상 상권의 종합 점수를 확인할 수 있다.                   | 상권별 탐색 점수를 비교 표시한다.                                      |
|  9-3  | 비교 대상 상권의 추정 매출을 비교할 수 있다.                   | 상권별 매출 원천값과 표시값을 제공한다.                                |
|  9-4  | 비교 대상 상권의 거래량을 비교할 수 있다.                      | 상권별 거래 건수를 표시한다.                                           |
|  9-5  | 비교 대상 상권의 매출 성장률을 비교할 수 있다.                 | 상권별 전분기 대비 성장률을 표시한다.                                  |
|  9-6  | 비교 대상 상권의 경쟁 여건을 비교할 수 있다.                   | 상권별 `CompetitionScore`와 Proxy 기반 경쟁 여건 등급을 표시한다.      |
|  9-7  | 비교 대상 상권의 주요 고객층을 비교할 수 있다.                 | 주요 연령대 정보를 표시한다.                                           |
|  9-8  | 비교 대상 상권의 주요 시간대를 비교할 수 있다.                 | 최고 소비 시간대 정보를 표시한다.                                      |
|  9-9  | 비교 대상 상권의 주요 요일을 비교할 수 있다.                   | 최고 소비 요일 정보를 표시한다.                                        |
| 9-10  | 비교 대상 상권의 경쟁 여건과 한계를 비교할 수 있다.            | Proxy 점수, 경쟁 여건 등급, 데이터 해석상 주의사항을 표시한다.         |
|  10   | 사용자는 백엔드 API를 통해 상권 데이터를 조회할 수 있다.       |                                                                        |
| 10-1  | 상권 목록 API를 호출할 수 있다.                                | `GET /api/v1/trade-areas`                                              |
| 10-2  | 특정 상권 API를 호출할 수 있다.                                | `GET /api/v1/trade-areas/{trade_area_code}`                            |
| 10-3  | 업종 목록 API를 호출할 수 있다.                                | `GET /api/v1/industries`                                               |
| 10-4  | 특정 업종 API를 호출할 수 있다.                                | `GET /api/v1/industries/{industry_code}`                               |
| 10-5  | 추천 상권 API를 호출할 수 있다.                                | `GET /api/v1/analytics/recommendations`                                |
| 10-6  | 상권 개요 API를 호출할 수 있다.                                | `GET /api/v1/trade-areas/{trade_area_code}/overview`                   |
| 10-7  | 상권 소비 패턴 API를 호출할 수 있다.                           | `GET /api/v1/trade-areas/{trade_area_code}/patterns`                   |
| 10-8  | 상권 경쟁 현황 API를 호출할 수 있다.                           | `GET /api/v1/trade-areas/{trade_area_code}/competition`                |
| 10-9  | 상권 비교 API를 호출할 수 있다.                                | `GET /api/v1/compare`                                                  |
| 10-10 | 서버 상태를 확인할 수 있다.                                    | `GET /health`, `GET /api/v1/health`                                    |
|  11   | 사용자는 데이터 조회 상태와 오류 상황을 구분해 확인할 수 있다. | Mock 데이터를 실제 API 오류의 정상 응답처럼 표시하지 않는다.           |
| 11-1  | 데이터 조회 중임을 확인할 수 있다.                             | API 요청 중 `loading` 상태와 `데이터 집계 중...` 문구를 표시한다.      |
| 11-2  | 데이터 조회가 정상적으로 완료되었음을 확인할 수 있다.          | API 응답 성공 시 `success` 상태의 실제 데이터를 표시한다.              |
| 11-3  | 조회 결과가 없음을 확인할 수 있다.                             | 정상 응답이지만 데이터가 없으면 `empty` 상태와 대안을 표시한다.        |
| 11-4  | API 오류가 발생했음을 확인할 수 있다.                          | HTTP 400·404·422·500·502·503을 정상 데이터로 대체하지 않는다.          |
| 11-5  | 서버 또는 네트워크 오류의 원인을 인지할 수 있다.               | 표준 `{ error: { code, message } }` 메시지와 재시도 수단을 표시한다.   |
| 11-6  | 운영 환경에서 오류가 기록된다.                                 | 오류 코드, HTTP 상태, 요청 경로, request ID 등 비민감 문맥을 로깅한다. |

## 미구현 기능

- 회원가입 및 로그인
- 사용자 계정 및 권한 관리
- 즐겨찾기 저장
- 검색어 기반 상권 검색
- 지도 기반 상권 탐색
- 실제 서울 열린데이터 연동
- 사용자별 비교 목록 영구 저장
- API 오류 상태 및 표준 오류 메시지 화면 표시
